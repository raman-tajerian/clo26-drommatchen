Vad var svårast att lösa?

Jag kände mig överlag ändå rätt bekväm med uppgiften eftersom jag valde att ta till mig uppgiften noga och anteckna steg för steg hur jag ville strukturera min kod. Trots det fastnade jag några gånger eftersom allt inte går som planerat, speciellt i grupp. Det var specifikt en sak som jag fastnade på. När det kom till properties hade jag i min kodfil skrivit med “gamla metoden” medan min gruppmedlem skrivit med auto-properties. Då fick vi börja diskutera och bolla med varandra vilken vi tyckte var bäst och det var mycket fram och tillbaka men beslutade till slut för att skriva med auto properties på grund av dess läsbarhet och enkelhet i koppling till denna specifika uppgift. 

Vad tog längre tid än du trodde — och hur kom du vidare? 

Det som tog längst tid var nog att faktiskt komma igång med uppgiften. Det är flera delar som kan kännas överväldigande i början men då är det viktigt att anteckna, gå igenom kraven, bygga ett tydligt skelett och en tydlig struktur innan man börjar skriva själva koden. Det som fick oss vidare från det var att sitta ner i onsdags och gå igenom allt tillsammans och diskutera hur vi vill lägga upp arbetet. Detta gjorde att jag uppskattade mycket att man jobbar i grupp då vi kan få motivation av varandra att börja. Därefter flöt själva koden på bra och tog inte alls lång tid förutom att skriva properties med gammal metod som kanske var den mest tidskrävande enskilda biten i koden.

Hur fungerade samarbetet i gruppen?

Vad fungerade bra?
Vår kommunikation fungerade väldigt bra, både när vi diskuterade tidsplan, när vi ville börja, hur vi skulle dela upp arbetet, vad som saknas och kan bli bättre i vår kod. Det var givande att kunna diskutera konstruktivt med varandra genom hela arbetet. 



Vad var svårt?
Det som var svårt var att jobba i Git som grupp, eftersom det var första gången för oss båda. Vi stötte bland annat på en merge-konflikt i en av filerna vilket kändes förvirrande i stunden. Vi löste det tillsammans i Visual Studio, och förstod därefter Git bättre. Det var bra övning i att hantera konflikter vilket man kan uppskatta nu i efterhand.


Hur delade ni upp arbetet
Som beskrivet i rapporten delade vi upp arbetet i olika kodfiler vilket fungerade bra och utan större problem. Rapporten skrev vi tillsammans i ett delat Google Docs som vi båda kunde redigera parallellt.

Om du fick göra om det - vad hade du gjort annorlunda?
I framtiden tror jag verkligen att det gör skillnad att sitta tillsammans fysiskt när man jobbar med större kodprojekt. Det känns enklare för mig att diskutera problem och lösningar effektivt när vi är på samma plats, så det är något jag har med mig inför framtida grupparbeten. 
Properties-situationen hade förmodligen kunnat undvikas om vi diskuterat och bestämt vilken kodstil vi skulle använda innan. Samtidigt är jag ändå glad att det hände, vi fick lära oss av varandra och landade i ett medvetet gemensamt val istället för att ha en kod som inte är konsekvent. Ett plus var ju ändå att jag fick skriva properties i både gammal och ny metod.
